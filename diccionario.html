B

  • BMP:

    (Basic Multilingual Plane) El primer plano de codificación del estándar Unicode (Plano 0), compuesto por los primeros 65,536 puntos de código, el cual contiene los caracteres, símbolos y escrituras más utilizados en la gran mayoría de los idiomas modernos del mundo.

    wikipedia.org codepoints.net

C

  • CSR:

    (Client Side Rendering) Técnica de desarrollo web en la que el servidor envía al navegador del usuario un archivo HTML básico y vacío junto con archivos de JavaScript; el propio navegador ejecuta ese código en el dispositivo del cliente para renderizar y construir todo el contenido visual de la página.

    developer.mozilla.org

D

  • DOM:

    (Document Object Model) Interfaz de programación (API) estructurada en forma de árbol que representa los elementos de un documento HTML o XML como objetos jerárquicos, permitiendo a lenguajes como JavaScript acceder, modificar, añadir o eliminar dinámicamente su estructura, estilo y contenido visual.

    developer.mozilla.org

L

  • LTS:

    (Long Term Support) Versión de un programa, sistema operativo o plataforma de desarrollo que recibe actualizaciones de seguridad y mantenimiento técnico garantizadas durante un período prolongado (generalmente de 2 a 5 años o más), priorizando la estabilidad del sistema sobre la introducción de nuevas funciones.

    • wikipedia.org

M

  • MIME:

    (Multipurpose Internet Mail Extensions) Estándar técnico que extiende el formato original del correo electrónico para permitir el intercambio de archivos que no son de texto plano, como imágenes, audio, video y documentos adjuntos, y que actualmente se utiliza también en la web (HTTP) para que los navegadores identifiquen correctamente el tipo de archivo que están descargando.

    wikipedia.org

S

  • SEO:

    (Search Engine Optimization) Conjunto de técnicas, estrategias y optimizaciones aplicadas al código, contenido y estructura de un sitio web con el objetivo de mejorar su visibilidad, relevancia y posición en los resultados orgánicos (no pagados) de los motores de búsqueda.

    wikipedia.org

  • SSH:

    (Secure Shell) Protocolo de red seguro que permite a los usuarios acceder, administrar y transferir datos de forma remota en una computadora o servidor a través de un canal de comunicación completamente cifrado.

    wikipedia.org

  • SSR:

    (Server Side Rendering) Técnica de desarrollo web en la que el servidor procesa el código de una aplicación para generar la página HTML completa ya armada y enviarla directamente al navegador del usuario, mejorando la velocidad de carga inicial y el posicionamiento en buscadores (SEO).

    developer.mozilla.org

T

  • TDD:

    (Test-Driven Development) Metodología de desarrollo de software en la que los programadores escriben primero las pruebas automatizadas que definen el comportamiento deseado, y luego desarrollan el código estrictamente necesario para que dichas pruebas se ejecuten y aprueben con éxito.

    wikipedia.org

U

  • URL:

    (Uniform Resource Locator) Dirección única y específica que se asigna a cada uno de los recursos disponibles en la red (como una página web, una imagen o un archivo) para que puedan ser localizados y accedidos a través de un navegador de internet.

    wikipedia.org

  • UTF:

    (Unicode Transformation Format) Familia de formatos de codificación que define las reglas técnicas para transformar los puntos de código numéricos del estándar Unicode en secuencias de bytes utilizables por las computadoras, permitiendo almacenar y transmitir texto en cualquier idioma de forma estandarizada.

    wikipedia.org
